Limitcast 0.20.7: doctor --fix keeps your hook wrappers

Sam Stull · 21 November 2026

Limitcast 0.20.7 is available on npm. Reinstalling Limitcast or running limitcast doctor --fix now keeps a wrapper you put around a Limitcast hook command, instead of replacing the whole command with a bare one.

All features remain free under the MIT License. Limitcast runs locally on macOS and Linux with Node.js 22 or later. The Claude Code, Codex and Grok plugins have also been updated to 0.20.7.

Keep your wrapper around a hook

Some setups run a hook through a small adapter, for example a script that decides which tool a hook applies to and then runs sh -c '<limitcast command>'. Limitcast found its command inside such a wrapper, recognised it as its own, and on reinstall replaced the entire command with a fresh, unwrapped one. The adapter was silently removed, so the hook ran in places it was meant to skip.

The most common trigger was routine: after brew upgrade limitcast, doctor reports that Node or Limitcast moved and suggests doctor --fix, which reinstalls the hooks.

Version 0.20.7 updates only the Limitcast invocation inside the wrapper and leaves the rest of the command exactly as you wrote it. When the large-output notice is folded into the optimizer hook, --notice is now added inside the wrapper, not after its closing quote. If the wrapped command points to a launcher path that no longer exists, the current command replaces it, so a stale path is never kept.

Also since the last release post: 0.20.6

  • Transcripts are split into lines on newlines only. A record containing U+2028 or U+2029, common in scraped web text, was torn into unreadable pieces, so limitcast trim reported an incomplete history and the token and startup readers dropped that record.
  • limitcast trim suggests hiding only skills that skillOverrides can hide. Plugin and bundled skills are no longer listed or counted in the removable estimate.

How the release was checked

Two regression tests cover keeping a wrapper, placing --notice inside it, and replacing a wrapper whose launcher moved. The 0.20.7 release commit passed 336 tests and all eight CI jobs, and the publication preflight confirmed both before the package was published. The tarball downloaded from npm has the same checksum as the tested package, and the GitHub release and Homebrew formula use that file.

On a real configuration with ten wrapped Limitcast hooks, the previous version's doctor --fix removed the wrapper from six of them. With 0.20.7 the same repair updated the launcher and left the hook settings unchanged.

Upgrade

npm install -g limitcast@0.20.7
# or
brew upgrade limitcast

Then run limitcast doctor. If it suggests a repair, limitcast doctor --fix is now safe to run on wrapped hooks. Restart Claude Code, Codex and Grok afterwards. The full list of changes is in the 0.20.7 release notes.
