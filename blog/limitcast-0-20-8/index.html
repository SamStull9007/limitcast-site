Limitcast 0.20.8: native Windows install

Sam Stull · 23 November 2026

Limitcast 0.20.8 is available on npm, GitHub, and Homebrew. It installs natively on Windows with Node.js 22 or later and Git for Windows. WSL is optional.

All features remain free under the MIT License. Limitcast runs locally on macOS, Linux, and Windows. The Claude Code, Codex, and Grok plugin manifests in the repository are 0.20.8.

Install on Windows

Install Node.js 22 or later and Git for Windows, then run the same npm install -g limitcast and limitcast install commands in PowerShell, Command Prompt, or Git Bash. Use npm.cmd if PowerShell blocks npm.ps1. Limitcast uses Git Bash for its hook launcher and keeps Windows paths that contain spaces. If Git Bash is installed somewhere other than the default location, set CLAUDE_CODE_GIT_BASH_PATH to its bash.exe before installing and starting Claude Code.

An existing status-line command needs to run in Git Bash. For a PowerShell script, invoke powershell -NoProfile -File C:/path/script.ps1. Desktop alerts use Windows PowerShell notifications. limitcast notify test checks whether Windows permits them. Opening the results dashboard works from the Windows install as well.

Also in this release

  • Windows lock contention and orphan recovery, transcript path detection, and model-worker timeout cleanup.
  • The test suite and a packed npm install run on Windows, macOS, and Linux with Node 22, 24, and 26.

How the release was checked

The release commit d663a2c passed all eleven CI jobs: lint, security, and tests on Windows, macOS, and Linux for Node 22, 24, and 26. The npm package checksum matches the tarball attached to the GitHub release, and the Homebrew formula installs that file.

Upgrade

npm install -g limitcast@0.20.8
# or
brew upgrade limitcast

Then run limitcast doctor. If the hook launcher still points at an older install, limitcast doctor --fix rewrites that launcher and keeps a wrapper you put around a Limitcast hook command. Restart Claude Code, Codex, and Grok afterwards. The full list of changes is in the 0.20.8 release notes.

limitcast forecasts when each Claude Code, Codex and Grok window runs out, and holds runaway subagents before they burn the rest of it. It is free and MIT licensed.
