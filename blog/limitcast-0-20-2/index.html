Limitcast 0.20.2: a metadata-only patch

Sam Stull · 17 November 2026

Limitcast 0.20.2 is available on npm, GitHub and Homebrew. It changes no code and no behavior. The only change to the package is its metadata: the npm author field now carries a public contact address and a link to the maintainer page.

Limitcast forecasts usage limits and provides optional controls for Claude Code, Codex and Grok. All features remain free under the MIT License. Version 0.20.2 requires Node.js 22 or later on macOS or Linux.

What changed

In 0.20.1 the npm package named its author as plain text. In 0.20.2 the field reads: 

"author": "Sam Stull <support@limitcast.dev> (https://limitcast.dev/sam-stull/)"

The npm package page can now point to the maintainer page and to the project's public contact address, support@limitcast.dev. That address is the one the project already uses for questions and for commits.

The plugin manifests for Claude Code and Codex moved to 0.20.2, and the plugin's slash commands now pin limitcast@0.20.2. Commands from an older plugin keep running the 0.20.1 package until you update the plugin.

What did not change

I compared the published 0.20.1 and 0.20.2 tarballs file by file. Both contain 50 files, and the only file that differs is package.json. Two lines differ in it: the version number and the author field.

Nothing in the forecasts, the guard, trimming, the optimizer or any host integration changed. If you are happy with 0.20.1, you lose nothing by staying on it. See the 0.20.1 update for the last release that changed behavior.

What was verified

The release passed 316 tests and lint, and all eight GitHub CI jobs succeeded on the release commit. The tarball downloaded from the npm registry matches the one attached to the GitHub release, and the Homebrew formula's checksum verifies against it.

Because the code is identical, these checks add little beyond confirming that the release was assembled correctly. They do not measure token savings, and this release makes no new claim about them.

Upgrade to 0.20.2

The upgrade is optional. To move to it, use the package manager you installed Limitcast with. For npm: 

node --version
npm install -g limitcast@0.20.2

For an existing Homebrew installation:

brew update
brew upgrade samstull9007/limitcast/limitcast

Check the result with:

limitcast --version
limitcast doctor

If you already installed the plugin, update it in each host you use. For Claude Code: 

claude plugin marketplace update limitcast
claude plugin update limitcast@limitcast --scope user

For Codex:

codex plugin marketplace upgrade limitcast
codex plugin add limitcast@limitcast

For Grok:

grok plugin update limitcast

Restart open Claude Code, Codex and Grok sessions to load the refreshed plugin definitions and version-pinned commands.
